# 공구 리스트

공동구매 품목과 선점자를 폰에서 바로 보는 개인용 앱.
서버·DB·로그인 없음. 파일 몇 개가 전부고, 데이터는 기기 안에만 저장됩니다.

## 2. 폰에서 앱처럼 쓰기 — GitHub Pages

한 번만 해두면 그 뒤로는 PC도 서버도 필요 없습니다.
이 저장소를 **Fork** 하거나, 파일을 받아서 본인 저장소에 올리면 됩니다.

```bash
cd 공구리스트-폴더        # 파일을 받아 둔 폴더로 이동
git init
git add .
git commit -m "공구 리스트 앱"
git branch -M main
git remote add origin https://github.com/<본인-아이디>/<저장소-이름>.git
git push -u origin main
```

그다음 GitHub 저장소에서 **Settings → Pages → Source: `main` / `(root)`** 선택.
1~2분 뒤 `https://<본인-아이디>.github.io/<저장소-이름>/` 주소가 생깁니다.

폰에서 그 주소를 열고:

- **아이폰(Safari)** — 공유 버튼 → `홈 화면에 추가`
- **안드로이드(Chrome)** — 메뉴 → `홈 화면에 추가` 또는 `앱 설치`

이제 아이콘을 누르면 주소창 없이 앱처럼 뜨고, **비행기 모드에서도 열립니다.**

> ⚠️ 무료 GitHub Pages는 **주소를 아는 사람은 누구나 볼 수 있습니다.**
> 검색 노출은 막아뒀지만(`noindex`) 완전한 비공개는 아닙니다.
> 비공개가 꼭 필요하면 Netlify의 비밀번호 보호나 GitHub Pro의 비공개 Pages를 쓰세요.

## 3. 기본 데이터 고치기

저장소에 들어 있는 기본 데이터는 **가상의 예시**입니다 (홍길동·김철수 등).
처음 쓰실 때 본인 데이터로 갈아끼우세요.

[`data.js`](data.js) 안의 `groups` 를 고치고 **맨 위 `version` 숫자를 1 올린 뒤** push 하세요.

```js
window.GONGGU_DATA = {
  version: 2,          // ← 고칠 때마다 1씩 올리기 (안 올리면 반영 안 됨)
  groups: [
    {
      id: "g-1030-xmas",          // 겹치지 않는 아무 문자열. 나중에 바꾸지 말 것
      title: "10/30 크리스마스 공구",
      date: "2025-10-30",
      type: "host",               // host = 내가 연 공구 / joined = 내가 참여한 공구
      items: [
        { id: "i-1030-1", name: "산타 치이카와", qty: 1, price: 22000, holders: ["홍길동"] },
        { id: "i-1030-2", name: "루돌프 우사기", qty: 2, price: 22000, holders: ["최지우", "김철수"] }
      ]
    }
  ]
};
```

- **총계는 적지 않습니다** — `qty × price` 로 자동 계산됩니다
- `holders` 는 배열이라 한 품목에 여러 명을 넣을 수 있습니다
- `type: "joined"` 인 공구는 마지막 열 이름이 자동으로 **선점자 → 공구주** 로 바뀝니다

push 하고 나면 앱에 **"새 기본 데이터가 있어요"** 배너가 뜨고,
누르면 반영됩니다. 이때 **앱에서 직접 추가한 공구·품목은 지워지지 않습니다.**

## 4. 데이터가 어디에 저장되나

| | 저장 위치 | 기기 간 공유 |
|---|---|---|
| `data.js` 의 기본 데이터 | 깃 저장소 | O (push하면 모두 반영) |
| 앱에서 직접 추가·수정한 것 | 그 기기의 브라우저 (localStorage) | **X** |

즉 앱 안에서 넣은 데이터는 **그 폰에만** 남습니다. 다른 기기로 옮기려면
`요약` 탭의 **JSON으로 내보내기 → 다른 기기에서 JSON 불러오기** 를 쓰세요.

브라우저 데이터를 지우거나 앱을 삭제하면 로컬 데이터도 사라지니,
중요한 내용은 가끔 내보내기로 백업하거나 `data.js` 에 옮겨 두는 걸 권합니다.

## 5. 기능

- **목록** — 내 공구 / 참여 공구 탭 · 전체·진행·완료 필터 · 필터별 누적 금액 · 완료/미입금 배지
- **상세** — 품목 / 갯수 / 단가 / 총계 / 선점자 표 + 합계 행 자동 계산
- **배송비** — 해배비·일내비 입력 후 **인원 기준 / 갯수 기준** 선택 분배, 사람별 직접 조정, 반올림/소수점 선택
- **정산표** — 선점자별 물품비 + 배송비 = 보낼 금액
- **입금 확인** — 한 번 탭으로 체크, 공구별 · 전체 미입금 집계, 입금 대기 목록
- **배송 정보 · 운송장** — 이름을 누르면 연락처·주소·메모(공구 간 공유) + 입금·운송장·배송비 조정(공구별)
- **오픈채팅 링크** — 공구별 링크 저장 후 바로가기
- **완료 처리** — 완료 버튼 + 유예기간(기본 20일) 후 자동 삭제 (기본 꺼짐)
- **검색** — 전체 공구 통합 부분 일치 검색, 매칭 부분 형광 표시
- **요약** — 내 지출 / 남의 몫(받을 돈) / 전체 분리, 선점자별 집계, 설정
- **내보내기** — JSON 백업/복원, 엑셀용 CSV(품목·정산)
- **화면 테마** — 자동(폰 설정) / 밝게 / 어둡게 직접 선택
- 오프라인 동작(PWA)
